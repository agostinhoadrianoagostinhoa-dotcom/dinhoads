Perguntas frequentes

Por onde começar a aprender?

Se nunca programaste, começa por Do Pensamento ao Código e depois passa ao Python. Se já sabes o que é um algoritmo e queres escrever código já, podes começar por Python para Iniciantes.

Preciso de computador?

Não para ler. Do Pensamento ao Código estuda-se com papel e lápis, e o Python para Iniciantes explica como seguir os exemplos num telemóvel Android.

Em que formato são os ebooks?

Ambos são ficheiros PDF, que podes ler no telemóvel, no tablet ou no computador.

Preciso de experiência anterior?

Não. Os dois ebooks foram escritos para iniciantes e explicam tudo desde o princípio.

Como é feito o pagamento?

A compra acontece no checkout de cada ebook. Lá vês o preço final, os métodos de pagamento disponíveis e como receber o ficheiro.
